## ✨ 功能

- **还原 MC-212 / MC-21650** – 重进存档可豁免坠落伤害（包括高处坠落时重进存档免死）
- **修复 MC-278261** – 重生无无敌问题

## ⚙️ 配置

配置文件位于 `.minecraft/config/safespawn.properties`，支持自定义：

```properties
invulnerableTicks=60          # 无敌时间（游戏刻，20 = 1 秒）
enableRespawnImmunity=true    # 死亡重生后无敌
enableLoginImmunity=true      # 登录时启用无敌（重进游戏时）
```
